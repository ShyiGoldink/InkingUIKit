# 锚点定位：InkingAnchor

**返回介绍目录：**
[介绍文档 index](index.md)

`InkingAnchor` 的存在是为了给项目中的每个内容提供一个基础定位能力。

## 核心结构：InkingAnchorPoint

它的核心在于 `InkingAnchorPoint` 这个小结构体。这个小结构体很简单，就是两个用于代表百分比的 `float`：

- `x` 用于描述横轴；
- `y` 用于描述纵轴。

以 UI 的左上角为 `0.0, 0.0`，右下角为 `1.0, 1.0`。

## 为什么用百分比

用百分比来描述锚点的位置，可以避免使用者去手算锚点的位置。特别是对于常见的居中这种内容。

所以我们也提供了一些快捷的常量，来帮助用户直接选择追踪的锚点。

## 为什么锚点在 LetterBox 下尤其可靠

由于 InkingUIKit 本身并不是一个通用 UI 库，而是一个 LetterBox 式的类型。

由于 LetterBox 本身就具有非常重要的所见即所得的能力，这里我认为锚点的定位能力是非常契合的：窗口缩放只改倍率、不改逻辑坐标。所以百分比锚点在任意窗口尺寸下比例都不变——换分辨率、拉窗口，都不需要改一行业布局。
