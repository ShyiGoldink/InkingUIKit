两条反馈**责任方都在库**，插件只是 `FilePickerStyle::MakeDefault()` 的消费者；核实时又量出同一处抽象错位的第三个后果（滚轮缩放）。拆成 **3 个任务、2 批**：第一批修行为（T-01 / T-02），第二批只做版本与文档收口（T-03）。

**两条不变量**（本轮判断一切取舍都用它们）：

1. **窗口语义只属于窗口层组件。** 全屏隐藏、滚轮缩放、标题栏接管、快捷键表都是"贴着窗口"的行为；对话框里的一行按钮不该继承，哪怕它长得一样。
2. **测量与布局读同一份几何。** 布局给"`SetVisible(false)` 的项仍占位"，那内容测量就**根本不看可见性**（只看矩形并集）——否则同一件事有两个事实。

本轮**不需要**改 GoldingCore 一行代码（`style.buttons` 在该仓库里从未被使用，只用 `extensions` / `acceptText`），它只需把 SDK 指到 0.5.3。

## 2. 基线事实（核实结论）

### 2.1 先说"为什么当初会用 MenuBar"

`FilePickerData.h` 的抬头把当年这条决定写得很直白：**"路线已由用户裁定：组装自绘……C2 菜单栏（底部按钮那一栏）。一条新的底层词汇都没有。"** 也就是说，当时为了守住"预制件不新增底层词汇"这条纪律，底部那一行去复用现成的 `MenuBar`——它确实是当时唯一"自己拥有子项 + 自带横向 Stack + 加项自动重排"的容器。

问题不在**布局复用**，在**策略复用**：`MenuBarData.h` 的数据面里除了 `panel` / `captionLook`，还捆着四件窗口级的事——`draggable`（:49）、`captionButtons`（:52）、`hideInFullscreen`（:77，**默认 true**）、`zoomWheel`（:92，**默认 true**）；实现里还有第三件：构造订阅 `fullscreenChanged`、析构解绑快捷键表。对话框的按钮行把这五件一起继承了，于是"看起来一样的东西"带上了"贴着窗口才成立的行为"。这不是手滑，是抽象边界划在了错的地方——所以本轮不是关开关，是把那一栏换掉。

### 2.2 逐条判定

| 条目 | 判定 | 证据 |
| - | - | - |
| 反馈 1：全屏后「添加 / 取消」消失 | **成立（库）** | `MenuBarData.h:77` `hideInFullscreen = true`；`MenuBar.cpp:118-141` 构造补一次 + 订阅 `fullscreenChanged` 自隐；`FilePickerData.h:66` `MenuBarStyle buttons`、`FilePicker.cpp:217` 直接 `MenuBarStyle::MakeDefault()`，从未置 false |
| 反馈 2：首次没有滑块，进子目录再退回才有 | **成立（库）** | `InkingStaticPanel.cpp:381-383` 只统计 `IsVisibleInTree()` 的子项；插件在弹窗还是 `visible=false` 时 `SetDirectory()` ⇒ 实测 `contentH=0`、竖条不出现；弹窗转可见后无人重量（`ListView.cpp:250-252` 可见区间没变就早退），只有换目录触发全量重建才量到一次 |
| 反馈 2 的量化偏差：内容高比实际少 70 | **成立（库，未被报告）** | 探针（链 0.5.1 SDK）：37 项目录真实内容高 `37×26=962`，量到 **892**；`rangeY` 592 而应为 662。原因：`InkingStaticPanel.cpp:377-390` 把**已是父级相对**的子项坐标又减了一次面板自身的 `GetX()/GetY()`（列表在 FilePicker 里的 y=70；0.5.2 加盘符栏后是 104） |
| 「插件在 `create` 里 `SetDirectory` 太早」 | **部分成立** | 是触发条件不是根因：同一份代码在"弹窗先显示再填充"时正常。T-02 之后该顺序不再有害，因此不改插件、也不改 `golding.popup` 的时序（见 §7） |
| 顺带：滚轮落在按钮行会缩放窗口 | **成立（未被报告）** | `MenuBarData.h:92` `zoomWheel = true` + `MenuBar.cpp:405-419` 滚轮直接 `InkingWindow::ZoomBy`；按钮行占选择器底部 40px，指针落在那一带滚轮 = 窗口跳档，列表不动。T-01 后自动消失 |

### 2.3 探针原始输出（0.5.1 SDK，可复跑）

```
[弹窗隐藏期 SetDirectory] 行=14 contentH=0   条=0        ← 反馈 2 的现场
[弹窗转可见 + Relayout  ] contentH=0   条=0             ← 没人重量
[之后任意一次换目录      ] contentH=892 条=1 thumb=98   ← 有条但数字不对（真值 962）
[37 项大目录             ] contentH=14906（真值 14976） ← 恒定少 70，不是累计漂移
```
