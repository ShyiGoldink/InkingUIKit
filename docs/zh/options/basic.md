关于 InkingUIKit 的一些基础决策。

## 一句话介绍

InkingUIKit 是一个基于 SDL3 的、C++ 的轻量级 UI 库。

## 两种形态

其分为两个种类：

- **InkingUIKit-L**：最轻量级的库，只提供最简单的 UI 组件。
- **InkingUIKit-E**：面向 2.5D 的游戏引擎设计的库。除了提供最简单的 UI 组件，还提供了 Field——场地。场地是一套只支持 2.5D 的内容，不过现在不多做解释。

## CXXCSS：声明式 UI

CXXCSS 是本项目的声明式 UI 的支持。

现在的决策与最初有些许出入：最终决定将 CXXCSS 移出核心功能，而是作为单独的附加功能，使用独立的 CLI 和可视化界面来实现内容。

之所以做 CLI，是为了面向 AI 支持——代表本库作为 2026 年 AI 时代下的新生者，有一切都支持 Agent 开发的决心。所以文档也写得十分详尽。

## 关于 SDL3

我倾向于不在头文件中引入 SDL3。并不是什么特别复杂的原因，而是单纯拒绝"向前依赖"：一旦 `include/` 下的头文件 `#include` 了 SDL 的头，每个包含本库头的编译单元都会被迫连带解析 SDL，编译内容凭空变多。

## 关于坐标

对于UI组件来说，左上角为零点。
