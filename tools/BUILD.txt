!! 升级提示
   0.5.1 **没有破坏性接口改动**：图片层新增 `type:"svg"`（整张设计稿运行期光栅化）与
   可选的 `hitPassThrough`（背景不吃点击）；按钮的 `svg` 子集与既有配置语义不变。
   但**从 0.5.0 之前升级**仍要处理 0.5.0 的指针钩子签名变化：
     旧  void onPointerPress(bool press) / void onPointerClick()
     新  void onPointerPress(PointerButton, bool) /
         void onPointerClick(PointerButton, float designX, float designY)
   不关心右键的组件在函数开头 `if (button != PointerButton::Primary) return;` 即可。
   完整迁移样板见 docs/zh/CHANGELOG.md 的「0.5.0 / 变更」第 1 条。

本版内容
  0.5.1（整张 SVG 设计稿）
    - 图片层支持 type:"svg"：整份稿在运行期按「组件尺寸 × 输出设备比例」光栅化成纹理，
      再按形状裁剪铺进框；同一张图最多 3 档缓存、单张上限 16M 像素。
      支持多图元 / g / transform / 线性与径向渐变 / 组透明度 / 嵌套 svg /
      stroke + dasharray / fill-rule="evenodd"；1600×900 实测首次光栅化 14 ms。
    - text / use / <image href> / clipPath / mask / filter 不渲染（nanosvg 边界），
      加载时打一条汇总 WARN（每张图一次）并进 TextCacheStats 计数——不再静默消失。
    - hitPassThrough（Image 顶层字段）：背景图不吃空白点击（默认 false 保持旧行为）。
    - 示例：CXXCSS/Image/design.json + examples/demo/assets/design.svg（铺满背景 + 上层控件）。
  0.5.0（右键 + 触摸长按，并入）
    - 统一输入状态 Primary / Secondary（PointerButton.h）：左键 / 右键 / 轻点 / 长按
      在组件层同构，组件不再需要知道设备。
    - 触摸长按 0.5s、位移 ≤ 8 设计像素 ⇒ 转义为一次完整次键交互。
    - 次键事件 contextClicked / SetOnContextClicked；捕获按按钮分槽，左右同按不互相顶掉。
    - 窗口关掉 SDL 触摸→鼠标合成；inside 判据补 INPUT_FOCUS 与 IsTouchActive。
  0.4.1（并入）
    - InkingFixedPopup（每轴翻转/夹紧 + 点外关 + 焦点模态）、MenuPopup、局部快捷键。
    - 动态组件采样改到"指针变化的那一帧"；边沿/捕获/点击统一到 detail::PointerProbe。
  0.4.0（并入）
    - 收集表按树 DFS 重建；容器命中递归进基类；增删孩子 / Resize 自动重排。
    - 无头能力：Open / PumpOnce / RunFrames、RenderToTexture、SetFixedDelta、
      PostFrameTask / RunAfterFrames、RequestClose(int) + Show 返回退出码。
    - 透明窗口、默认主题「现代浅紫」、字体回退链（0.3.0）。

怎么用
  1. 只想看效果：双击 bin/inking_demo.exe（ESC 退出，F11 全屏，右键有上下文事件）；
     或命令行跑 bin/inking_demo_selftest.exe，读末行"失败项：N"。
     **不需要 MSYS2、不需要改 PATH**——DLL 就在 exe 旁边。
  2. 写自己的工程：见 README「用预编译包」两条路线；最快的是把
     examples/minimal/ 整份拷出去改：
       cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
             -DCMAKE_PREFIX_PATH="<本包根>;C:/msys64/ucrt64"
       cmake --build build
     把 <本包>/bin/*.dll 拷到 exe 旁（minimal 的 CMakeLists 已自动做）。
  3. 前提：编译需要 MSYS2 UCRT64 的 cmake / ninja / gcc / sdl3 四件 / ffmpeg。
     **不能用 MSVC 链接本包**（MinGW 的 .dll.a 与 MSVC 的 .lib 不兼容）。
  4. 升级旧代码先看 CHANGELOG：0.5.0 的指针钩子签名是**破坏性**的；
     0.5.1 只新增能力（svg 纹理路 / hitPassThrough），不迁移也能编译。
  5. 排错先截图：设 `INK_CAPTURE=<路径>` 跑一次，比加日志快。
  6. 跑自检会在 exe 旁生成 LOG/ 目录（日志），不属于包内容，可删。

已知限制（详见 README「已知限制」）
  - 只在 Windows + MSYS2 UCRT64 + Ninja 构建过；Linux / macOS 未验证。
  - 中键只记状态、不派发；右键不产生 onPointerDrag；触摸只认第一根手指。
  - 长按阈值 0.5s / slop 8 设计像素是通用值，真机手感未调。
  - 单行输入框：多行、撤销 / 重做、Tab 焦点遍历、IME 候选窗定位未做。
  - 两种 svg 的边界不同：按钮的 AppearanceType::Svg 只认单图形（生成期转形状）；
    整张设计稿用 Image 的 type:"svg"（运行期按目标像素光栅化）。
  - SVG 里的 text / use / <image> / clipPath / mask / filter 不渲染，只打一条 WARN；
    导出时请把文字转曲、use 展开。整张稿也**不做元素级拆解**。
  - 没有 portal：子的 z 盖不过父级的兄弟，要压就抬容器自己。
  - 运行期换肤只覆盖颜色（按钮三态 / 面板两态 / 标签文字色）；字号 token 是编译期的。
  - 透明窗口只在部分后端成立（D3D11 实测可用；D3D12 / Vulkan 多数不行）。
